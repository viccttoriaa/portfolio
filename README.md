# Victoria Gomez — Portfolio

Web lista para GitHub Pages. Incluye seis videos, el carrusel de Momentum, las fotografías y todos los recursos. No requiere instalación ni compilación.

## Subir a GitHub

1. Extraer el ZIP en tu computadora.
2. Crear o abrir tu repositorio de GitHub.
3. Subir el contenido extraído conservando sus carpetas. index.html debe quedar en la raíz. No subir el ZIP sin extraer.
4. En Settings → Pages elegir Deploy from a branch, la rama main y /(root), y guardar.
5. GitHub mostrará el enlace cuando termine la publicación.

Contacto: victoriagomezm1204@gmail.com. El formulario abre la aplicación de correo del visitante con el mensaje preparado. El visitante revisa y envía el correo; no existe envío automático desde la web.

Para editar componentes y textos, utiliza el ZIP separado del código fuente. Las rutas relativas admiten páginas bajo usuario.github.io/repositorio/.

[Guía oficial de GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) · [Subir archivos](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)

## Esta edición ligera

Conserva los seis videos completos a 720 px de ancho con una compresión mayor para reducir el tamaño de la carga. Mantiene el correo de Victoria. Extrae este ZIP en una carpeta nueva y sube únicamente su contenido: index.html, client.js, style.css, favicon.svg, robots.txt, .nojekyll, README.md y las carpetas fonts, victoria y work. No añadir victoria-portfolio.html ni el propio archivo ZIP.
